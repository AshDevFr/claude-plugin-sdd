## Implementation Notes

- **This is the phase's load-bearing constraint.** The page is served from object storage
  because our own infrastructure is the thing likely to be down; the first version pulled
  Inter from Google Fonts, which has the same problem one layer down.
- The test checks `src="http`, `href="http` and `@import`. It is deliberately a regex over
  the output rather than a review habit, because this is exactly the kind of thing a later
  well-meant change reintroduces.
- Both colour schemes ship in the one stylesheet. No JavaScript, so no flash and nothing to
  fail.
