## Objective

Let someone subscribe without giving us anything, by writing a feed next to the page.

## Scope

### In Scope

- `feed.xml` written by `beacon render`
- One entry per incident update

### Out of Scope

- Email, and anything with a subscriber list, unless the owner picks option A

## Implementation Notes

- **Assumes the recommendation in the open design record**, which the owner has not
  confirmed. If they pick the hosted list instead, this task is replaced rather than
  amended.
- Atom, not RSS: required stable ids and unambiguous dates, both of which task 3.02 needs.
- Written by the same `render` call, so there is no second command to forget mid-incident.

## Acceptance Criteria

- [ ] `feed.xml` appears beside `status.html`
- [ ] One entry per update, newest first
- [ ] Validates as Atom 1.0

## Testing Strategy

- **Unit:** entry count and ordering against the example file.
- **Integration:** parse the output with `xml.etree` and assert required elements.
