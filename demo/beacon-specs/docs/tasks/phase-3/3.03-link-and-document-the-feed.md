## Implementation Notes

- A `<link rel="alternate">` is what readers autodiscover; a visible footer link is what a
  person finds. Both, they cost a line each.
- The link is relative, so it stays self-contained and survives whatever bucket and prefix
  the page ends up under.

## Acceptance Criteria

## Testing Strategy

  satisfies and an absolute one would not.
