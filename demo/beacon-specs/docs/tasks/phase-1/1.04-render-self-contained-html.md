## Implementation Notes

- `now` is a parameter with a default rather than a call to `datetime.now()` inside, so
  every page test is deterministic without patching the clock.
- Everything from the incident goes through `html.escape`. The incidents file is written by
  a human under pressure and will eventually contain a `<`.
- An empty file renders a real page saying so, not an error. A status page that 500s
  because nothing has broken yet is absurd.

## Acceptance Criteria

- [x] Every incident appears with its id as an anchor
- [x] Incident text is escaped
- [x] No `src="http`, `href="http` or `@import` anywhere in the output
- [x] An empty list still renders a page

## Testing Strategy
