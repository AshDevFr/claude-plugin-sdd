## Implementation Notes

- One breakpoint, not a grid system. The layout is one column at every width; this is about
  padding, the left rule and wrapping.
- **Found in the audit:** a long component list pushes the meta line's timestamp off the
  right edge at 360 px. That is the actual bug, and the reason this task is not just
  reducing padding.
- The mockup asks the owner about timeline density separately; do not guess it here.

## Acceptance Criteria

- [ ] No horizontal scrolling at 360 px with the example file
- [ ] The timestamp stays on screen when the badge wraps
- [ ] A test fails if a fixed width over 360 px is introduced

## Testing Strategy

- **Unit:** a regex over the stylesheet for fixed pixel widths above 360.
- **Manual:** 360, 390 and 414 px in a browser, both colour schemes.
