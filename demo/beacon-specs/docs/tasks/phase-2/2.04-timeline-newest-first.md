## Implementation Notes

- **Stored oldest first, rendered newest first.** The file is written in the order things
  happened, which is the only order an author can append in; the page is read by someone
  who wants the last line. Reversing at render keeps both true.
- The rule and the dots are CSS on the `<ol>`, so there is no extra markup per entry.
