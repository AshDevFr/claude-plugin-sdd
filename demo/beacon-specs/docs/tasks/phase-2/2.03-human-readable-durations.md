## Objective

Say how long an incident lasted in words, because "1:22:00" is not an answer.

## Scope

### In Scope

- `human_duration(delta)`
- The meta line for open and closed incidents

### Out of Scope

- Any live-updating clock, which the static-render decision rules out

## File Plan

## Implementation Notes

- Under an hour reads as minutes; past an hour, hours with padded minutes; past a day,
  days and hours. A whole number of hours drops the minutes entirely: "3 h", not "3 h 00
  min", because the padding reads as false precision.
- An open incident says "ongoing" rather than counting up. The page is static, so a
  rendered count would be wrong the moment it was uploaded.

## Acceptance Criteria

- [x] 22 minutes reads "22 min"
- [x] 2 h 40 reads "2 h 40 min"
- [x] 3 h exactly reads "3 h"
- [x] Over a day reads "1 d 5 h"
- [x] An open incident reads "ongoing"

## Testing Strategy

- **Unit:** `Duration` covers each boundary; `Page` asserts both the ongoing and the
  lasted forms against the example file.
