## Implementation Notes

- `__slots__` is not for memory. It makes a typo in an attribute name fail loudly instead of
  silently creating a field, which is the failure mode that would otherwise reach the page.
- `duration` is `None` while an incident is open. A running clock belongs to the page, not the
  model, and returning `now - started` here would make every test time-dependent.
- Error strings carry the position ("incident 3") because a TOML array gives us no other handle
  on which entry is wrong.

## Acceptance Criteria

- [x] `resolved` before `started` is refused
